# Sanción Digital - API Backend

Sanción Digital es una plataforma diseñada para la gestión automatizada de infracciones y sanciones. Este repositorio contiene el **Backend**, desarrollado como una **API RESTful** utilizando Laravel 11, enfocada en la escalabilidad, seguridad y facilidad de integración con clientes modernos (como React o aplicaciones móviles).

## Tecnologías utilizadas

* **Framework:** [Laravel 11](https://laravel.com/)
* **Lenguaje:** PHP 8.2+
* **Base de Datos:** MariaDB / MySQL
* **Autenticación:** Laravel Sanctum (Tokens de API)
* **Entorno de desarrollo:** Linux (Kubuntu/Budgie)
